# Teacher Observation & TNA System

Local tool for English teacher assessment (Grades 1-5, 6-8).

## Live URL
https://YOUR-USERNAME.github.io/tna-tool/

## Features
- Classroom Observation Rubric (13 domains, 64 indicators)
- Teacher Subject Knowledge Test (40 marks)
- TNA Self-Assessment (Google Form import)
- Auto-generated reports with PDF export
- Self-reflection PDF attachments
- Group dashboard with charts

## Data Privacy
All teacher data stays in your browser's localStorage.
Nothing is uploaded to this GitHub repo or any server.

## Tech
HTML · CSS · JavaScript · Chart.js
